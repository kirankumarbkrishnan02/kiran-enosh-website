# Kiran Enosh Group of Institutions

A modern, responsive web platform for **Kiran Enosh Group of Institutions, Gudur** — empowering students with future-ready skills in programming, software development, and emerging technologies.

## 📌 Project Overview
This project consists of a frontend user interface and a backend server to handle data, authentication, and APIs.

*   **Frontend:** Clean, casual, and responsive user interface built with HTML, CSS, and JavaScript.
*   **Backend:** Node.js & Express server handling API requests, routes, and database connections.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Live Server
*   **Backend:** Node.js, Express.js, Nodemon, Gmail API (Mailer)
*   **Database:** MySQL (assumed based on previous file structure)

## 🚀 How to Run Locally

### 1. Start the Backend Server
Open your terminal and navigate to the backend folder:
```bash
cd kiran-enosh-website/backend
npm install
npm run dev



Start the Frontend
Open the frontend folder in VS Code. Right-click on index.html and select "Open with Live Server" (or simply double-click index.html to open it in your browser).
